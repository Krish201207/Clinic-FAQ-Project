How to interpret the result

  • gemini_package_installed: false — check requirements.txt.
  • api_key_set: false — GEMINI_API_KEY is missing from Render.
  • llm_configured: false — the Gemini client was not created.
  • cpp_ready: false — the C++ engine did not compile; check Render logs and required C++ files.
  • generation_error — the exception raised while calling Gemini.
